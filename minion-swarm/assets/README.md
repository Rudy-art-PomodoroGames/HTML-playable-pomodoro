# Minion Swarm assets

Drop art here with these exact file names. Anything missing falls back to the
game's built-in drawn shape (or the default font), so the game never breaks.

| File | What it is | Suggested size |
| --- | --- | --- |
| `background.png` | Play area background (stretched to fill) | 720×1120 |
| `minion_lv1.png` … `minion_lv8.png` | Minion art per merge level (levels above 8 reuse them in a cycle) | 128×128, transparent |
| `resource_small.png` | Small resource (bush) | 64×64 |
| `resource_big.png` | Big resource (tree) | 128×128 |
| `tap_marker.png` | Marker shown where the player taps | 64×64, transparent |
| `font.woff2` (or `.woff`, `.ttf`, `.otf`) | Font for all game text | — |

Images must be PNG. Keep files small: ad networks often cap a playable at 2–5 MB in total.

The easiest way to get a file with the right name: in the game, open 🎨, tap
**Replace** to try your art, then **Download**. Upload the downloaded files here
with GitHub's **Add file → Upload files**.
